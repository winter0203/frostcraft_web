# FrostCraft · 纯净生存服务器

> 坚守原版生存，不魔改游戏机制。

FrostCraft 是一个 Minecraft 纯净原版生存服务器，支持 Java 版与基岩版双端互通。不限制玩家行为（但绝不能作恶），可自由发挥创造力——红石/生电玩法完整保留，自动化农场、刷怪塔与工业体系均可自由搭建，养老休闲与技术钻研两相宜。

## 服务器特色

- **挂机假人** — 即便玩家下线，建造的机器也可持续运行
- **强劲性能** — 即便是大型高频红石机器，服务器也能轻松运行
- **双端支持** — 支持 Java 和基岩双端，手机电脑均可加入
- **公益运营** — 没有充值项目，资金来源于赞助

## 技术栈

- 前端：HTML + Tailwind CSS + 原生 JavaScript
- 部署：Cloudflare Pages
- 服务器状态接口：Cloudflare Pages Functions（Minecraft Server List Ping 协议直连游戏服务器）
